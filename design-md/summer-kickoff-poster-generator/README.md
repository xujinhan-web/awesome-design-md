# Summer Kickoff Poster Generator DESIGN.md

A whimsical, summer-themed mobile poster generator for creating a cute World Cup-style team memory.

## Design direction

- Soft hand-drawn chibi football style with pastel tones and thick rounded ink outlines.
- Landing page uses the provided puppy-football summer illustration as a full-bleed background.
- Generator page lets users enter three player names and previews them as paper labels above cute footballers inside a Polaroid-style frame.
- Mint CTAs, cocoa outlines, cream cards, and light-blue studio surfaces keep the app warm and playful.

## Usage

Copy `DESIGN.md` into your project root and ask your coding/design agent to build the two-screen poster generator. If the background asset is available locally, set it as the landing screen background and apply the readability overlay described in the `landing.background` rules.
